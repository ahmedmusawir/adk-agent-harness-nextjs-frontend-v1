## Architecture cheat-sheet (cold-start orientation)

- **Chat path:** UI → `chatService` (mode-flagged) → `/api/agent/run|history`
  (route handlers) → `_lib/adk.ts` native connector → ADK bundle `api_server`.
  Session bootstrap `session-${Date.now()}`, not-found→create→retry-once,
  response = last `content.role==='model'` text part.
- **Manifest:** `config/agents.manifest.json` (bundles carry env-var NAMES, never
  URLs) + validated loader `src/config/manifest.ts`. Adding an agent = JSON edit.
- **Sessions (Projects):** `chat_sessions` Supabase table = INDEX only (never
  transcripts) via `sessionIndexService`; SessionPanel in sidebar; localStorage =
  active-pointer cache, mode-namespaced `adk-session-map-live|-mock` (FIX-003).
- **Mission Control:** `instructionsService` (mode-flagged) →
  `/api/agent/instructions` → GCS, backup-before-write to `versions/*.bak`, ADC.
- **Persistence fence (sacred):** localStorage holds pointers + selectedAgent ONLY;
  the DB index holds metadata only; transcripts live in ADK exclusively.
- **Mock mode is the fail-safe default everywhere** (`NEXT_PUBLIC_CHAT_MODE=live`
  is the only live switch; anything else = mock, all three services + persist key).
